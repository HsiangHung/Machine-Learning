# Campaign Image Generation

This prototype code demos to generate images for campaign. 

It assumes our customers are marketers from Coca Cola. They request to generate a campaign and require the scenario as a BBQ party but only with Coke (no other drinks).

Without fine-tuning, the campaign image shows improper content:

<img src="https://github.com/HsiangHung/Machine-Learning/blob/master/GenAI/Inference/Brand/images/bug_campaign.png" width="600">

We see the bottles and can colors are not correct, and some folks look strange.

Without fine-tuning, the images can pivot as

<img src="https://github.com/HsiangHung/Machine-Learning/blob/master/GenAI/Inference/Brand/images/better_campaign.png" width="600">


Of course, there are still a lot room to pivot the results by tuning hyperparameters, codes and models. This is for fun!
